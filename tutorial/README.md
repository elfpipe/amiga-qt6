# Building Qt6 Applications for AmigaOS4 Using a Linux Cross-Compiler

This tutorial explains how to build **Qt6 applications for AmigaOS4** using a Linux-based cross-compilation environment. It covers toolchain setup, configuration, and building via both `qmake` and `cmake`. At the end, you’ll find a small example project.

---

## 1. Introduction

**AmiQute** is a port of Qt6 for AmigaOS4, enabling modern C++ GUI development on classic Amiga hardware or next-generation AmigaOS4 systems.

To make development efficient, a cross-compilation setup is used on Linux.

---

## 2. Requirements

You will need:

* A modern Linux system (e.g., Ubuntu, Fedora, Arch)
* A cross-compile environment for AmigaOS4 with Qt6 support
* A `clib4`-compatible GCC toolchain
* A working Qt6 installation on the host (Linux) system

---

## 3. Download and Install the Cross-Compile environment

Download the Qt6 AmigaOS cross-compiler archive:

👉 [Download here](https://github.com/elfpipe/amiga-qt6/releases/tag/v6.2.0public-static)

This archive contains both the Amiga Qt6 SDK and wrapper scripts for `qmake` and `cmake`.

### Installation:

1. Extract the archive \*\*directly to \*\* `\`:

   ```bash
   sudo tar -xvf qt6-amiga-6.2.0.tar.gz -C /
   ```

2. Ensure the clib4-compatible GCC toolchain from **AmigaLabs** is installed.

   * This must match the toolchain expected by the Qt6 Amiga setup.

---

## 4. Set Up the Qt6 Host Build

In order to build the Amiga Qt6 binaries, you also need a Qt6 installation on your **host Linux system**.

### Option 1: Use your distro’s package manager

```bash
sudo apt install qt6-base-dev qt6-tools-dev
```

### Option 2: Use the minimal host Qt6 from the GitHub release

* This is also located at the same GitHub link under `qt6-linux-host`.

### Configuration:

Edit the file:

```bash
/qt6-amiga/bin/qmake-amiga
```

Update the paths at the top of the script so it knows where to find:

* The **host qmake** (from your Linux Qt6 installation)
* The **AmigaOS cross-compiler binaries**

---

## 5. Building Amiga Qt6 Apps

Once the environment is configured, you can build Qt6 apps for Amiga using either `qmake` or `cmake`.

### With `qmake-amiga`

```bash
qmake-amiga
make -j$(nproc)
```

### With `qt-cmake-amiga`

```bash
mkdir build
cd build
qt-cmake-amiga ..
make -j$(nproc)
```

## 6. Example Project (Generated by ChatGPT)

### File: `main.cpp`

```cpp
#include <QApplication>
#include <QPushButton>

int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    QPushButton button("Hello AmiQute!");
    button.resize(200, 60);
    button.show();
    return app.exec();
}
```

### File: `amiqute.pro`

```pro
QT += widgets
SOURCES += main.cpp
```

### Build:

```bash
qmake-amiga amiqute.pro
make -j$(nproc)
```

The output will be an AmigaOS4-compatible binary you can transfer to your Amiga.

---

## 7. Running on AmigaOS4

To run your application on AmigaOS4:

1. Transfer the binary to your Amiga system.
2. Make sure all required Qt6 shared libraries (read: just clib4.library) are present (from AmiQute’s runtime distribution).
3. Optionally use `QtLaunch` or a script to initialize any environment variables.

---

## 8. Tips

* You can use `file` to verify the output:

  ```bash
  file myapp
  # Should show: AmigaOS4 executable
  ```

* Use `strip` from your cross-toolchain to reduce size:

  ```bash
  powerpc-amigaos-strip myapp
  ```

* Set up an `.AppDir` structure to bundle your app and Qt libs easily.
